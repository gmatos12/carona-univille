## Métricas de testes e cobertura

Última medição do backend com Vitest + V8 (41 arquivos de teste, 333 testes aprovados):

| Métrica | Cobertura |
| --- | --- |
| Linhas | 91,17% (2665/2923) |
| Funções | 92,01% (634/689) |
| Branches | 80,88% (2141/2647) |
| Statements | 88,07% (2916/3311) |

O frontend possui 3 testes aprovados. A meta mínima de 80% é validada pelo comando abaixo.

Para gerar ou atualizar o relatório HTML em `backend/coverage/` (abertura em `backend/coverage/index.html`):

```bash
cd backend
npm run test:coverage
```
